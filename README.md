# Сервис управления рассылками

Веб-приложение на Django для управления рассылками сообщений, 
администрирования и получения статистики.

## Функциональность

- Управление получателями рассылок (CRUD)
- Управление сообщениями (CRUD)
- Управление рассылками (CRUD)
- Ручная отправка рассылок с проверкой времени
- История попыток отправки
- Статистика на главной странице
- Регистрация с подтверждением email
- Восстановление пароля
- Ролевая модель: пользователь и менеджер
- Кеширование через Redis (серверное и клиентское)

## Технологии

- Python
- Django
- PostgreSQL
- Redis

## Запуск

1. Установить зависимости: `poetry install`
2. Применить миграции: `python manage.py migrate`
3. Создать суперпользователя: `python manage.py createsuperuser`
4. Запустить Redis: `brew services start redis`
5. Запустить сервер: `python manage.py runserver`
6. Открыть: `http://127.0.0.1:8000/`

## Роли

- **Пользователь** — создаёт и управляет своими рассылками и получателями, видит свою статистику.
- **Менеджер** — видит все рассылки и получателей, может блокировать пользователей и отключать рассылки. Не может создавать и редактировать.
